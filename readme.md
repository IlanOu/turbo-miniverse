# Turbo Miniverse

Un jeu de course et d'exploration où vous incarnez une petite voiture jouet dans une chambre d'enfant.

**Concept :** Retrouvez 3 clés cachées dans la chambre pour ouvrir 3 coffres à jouets contenant les pièces nécessaires à la reconstruction de votre piste de course.

**Gameplay :**

- Explorez librement une chambre d'enfant transformée en monde d'aventure
- Collectez des pièces brillantes pour acheter de nouvelles voitures
- Chaque véhicule offre des caractéristiques différentes (vitesse, maniabilité)
- Personnalisez votre collection au garage

Simple, amusant et accessible - TOY RACER combine course, exploration et collection dans un univers familier vu à travers les yeux d'un petit jouet.
